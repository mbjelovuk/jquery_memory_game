# Memory Game

**University:** University of Belgrade, School of Electrical Engineering  
**Course:** Web Design  
**Year:** 2025/2026  

## Overview

A browser-based memory card game developed using HTML, CSS and JavaScript.

The goal of the game is to find all pairs of identical cards in as few moves as possible. Cards are randomly shuffled at the beginning of each game, and the player reveals two cards at a time to find matching pairs.

## Features

- Multiple difficulty levels:
  - Easy – 2×3
  - Medium – 4×4
  - Hard – 5×6
- Classic game mode
- Timed game mode
- Randomized card layout
- Move counter
- Game timer
- Match detection
- Temporary card flipping for unmatched pairs
- Scoreboard for completed games
- Player name entry for recorded results

## Game Modes

### Classic Mode

The player attempts to find all card pairs using the smallest possible number of moves. The game ends when all pairs have been matched.

### Timed Mode

The player has a limited amount of time to find all pairs. The game ends unsuccessfully if the timer reaches zero before all pairs are found.
